# i18n + Sidebar Design Spec

**Date:** 2026-05-26
**Status:** Draft

## Overview

Add i18n support (English, Korean, Japanese) to TryCloudflareGUI. Japanese uses Pretendard JP font. Language auto-detects from system settings with a manual dropdown override in a new sidebar. The sidebar also provides quick-start preset shortcuts for common development servers.

## i18n Architecture

| Choice | Decision |
|--------|----------|
| Library | `react-i18next` + `i18next-browser-languagedetector` |
| Detection | Auto-detect from `navigator.language`, fallback to `ko` |
| Persistence | `localStorage` key `i18nextLng`, overrides auto-detect when set manually via dropdown |
| Files | JSON translation files: `src/renderer/src/i18n/locales/{en,ko,ja}.json` |
| Setup | `src/renderer/src/i18n/index.ts` initializes i18next config |
| Usage | `useTranslation()` hook. All ~30 hardcoded Korean strings replaced with `t('key')` calls |
| Key naming | Flat keys grouped by UI context (e.g., `tunnelCard.start`, `form.confirm`, `empty.noTunnels`) |

## Language Switcher

- Dropdown `<select>` in the sidebar with label "언어 / Language / 言語"
- Options: 한국어 (ko), English (en), 日本語 (ja)
- Changing the dropdown calls `i18n.changeLanguage()` which persists to localStorage and updates `body[data-lang]` attribute for CSS font switching

## Font Strategy

- Existing `pretendard-gov` (Korean-optimized) remains for ko/en
- Add `pretendard-jp` npm package for Japanese (note: exact package name TBD during implementation -- may be `pretendard-jp`, `@pretendard/jp`, or similar; verify on npm)
- Copy JP subset woff2 files from npm package to `public/woff2-dynamic-subset-jp/` (same pattern as current GOV files in `public/woff2-dynamic-subset/`)
- Create `public/pretendard-jp.css` with `@font-face` rules pointing to `./woff2-dynamic-subset-jp/` (mirroring GOV CSS pattern)
- `index.css` line 2: `@import "/pretendard-jp.css";`
- CSS rule `body[data-lang="ja"]` sets `font-family` to prefer `"Pretendard JP Variable"` before GOV and other fallbacks
- Vite resolve alias for `pretendard-jp` package added to `vite.config.ts` (same pattern as existing `pretendard-gov` alias)

### No Main Process Changes

i18n is purely renderer-side. The main process, preload, and IPC channels are unchanged.

## Error Handling

- i18next initialization failure: fallback to Korean (hardcoded as backup in `init` config)
- Missing translation key: i18next returns the key itself as fallback string (visible in UI as debug aid)
- Font loading failure: CSS font-family fallback stack handles missing JP font gracefully
